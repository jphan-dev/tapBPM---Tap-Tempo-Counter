# TapBPM — support site

The support, privacy, and terms pages for **TapBPM**, a free tap tempo app for iPhone.

Live pages (after GitHub Pages is turned on):

- Support — `https://USERNAME.github.io/tapbpm/`
- Privacy Policy — `https://USERNAME.github.io/tapbpm/privacy.html`
- Terms of Use — `https://USERNAME.github.io/tapbpm/terms.html`

Replace `USERNAME` with your GitHub username.

## Before publishing

Open all three HTML files and replace `YOUR-EMAIL@example.com` with a real
address. App Review does click these links.

## Turning on GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**,
folder **/ (root)** → Save. Give it two minutes, then reload.
